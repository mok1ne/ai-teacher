# Время сдавать — ИИ-репетитор для ЕГЭ и ОГЭ (MVP)

Веб-приложение: лендинг → бесплатная диагностика → прогноз балла и слабые темы → разбор с ИИ-репетитором (с привязкой к источникам ФИПИ) → прогресс → оформление подписки родителем.

Стек: **React 18 + Vite + React Router**, иконки **lucide-react**. Состояние между страницами — через React Context. Вызов ИИ изолирован в одном слое (модель-агностичный).

## Запуск локально

Нужен **Node.js 18+**.

```bash
npm install
npm run dev        # http://localhost:5173
```

Сборка для продакшена:

```bash
npm run build      # результат в dist/
npm run preview    # предпросмотр сборки
```

> ⚠️ В режиме `npm run dev` чат **не отвечает**, потому что нет бэкенда `/api/chat`.
> Чтобы чат заработал локально — запускайте через `vercel dev` (см. ниже) или задеплойте.

## ⚠️ Подключение ИИ (обязательно для рабочего чата)

Ключ Anthropic **нельзя** держать в браузере. Поэтому фронтенд (`src/lib/api.js`) шлёт запрос на ваш бэкенд `/api/chat` (`api/chat.js`), а тот добавляет секретный ключ и ходит в Anthropic.

1. Получите ключ на https://console.anthropic.com
2. Задайте переменную окружения (в хостинге или локально в `.env`):
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```
3. Запуск с работающими функциями локально:
   ```bash
   npm i -g vercel
   vercel dev        # поднимает фронтенд + /api/chat
   ```

Сменить модель ИИ можно в `src/lib/api.js` (`model: "claude-sonnet-4-6"` → `"claude-haiku-4-5-20251001"` для экономии).

### Переход на российскую модель (для школ / госсегмента)

Меняется только `api/chat.js` — URL, заголовки авторизации и формат тела под **YandexGPT** или **GigaChat**. Фронтенд и логика RAG/промптов остаются прежними.

## База знаний ФИПИ (гарантия «без выдумок»)

`src/data/knowledgeBase.js` содержит проверенные источники по темам. При разборе темы источник подмешивается в промпт, модели запрещено выходить за его пределы, и он показывается ученику в чате.

Это рабочий, но упрощённый RAG. Для продакшена замените `getSource()` на настоящий поиск: загрузите официальные материалы ФИПИ → векторный индекс (pgvector/Qdrant) → доставайте релевантные фрагменты по запросу. Формат `{ ref, content }` уже совпадает с тем, что вернёт бэкенд.

## Юридическое (РФ)

- MVP работает **анонимно** (без имени/возраста) — это снимает необходимость согласия родителей по 152-ФЗ на этапе теста.
- При платной модели регистрируется и даёт согласие **родитель** (законный представитель).
- Перед публичным запуском согласуйте обработку данных несовершеннолетних с юристом.
